# httk-sym reference data (downloaded, not versioned)

Source of truth: the [httk Spacegroup Data Explorer](https://symdata.anyterial.se/)
(httk-symgen datasets, generated from cctbx, spglib and spgrep).

License: **CC-BY 4.0** — attribution required; see the attribution note in the
repository README.

Fetch and extract (the archives arrive as .json.gz):

    python3 scripts/data/download_httk_sym.py

The JSON files are gitignored; this folder only carries this README.
